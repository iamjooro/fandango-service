# Завышал ли Fandango рейтинги фильмов

Статистическая проверка обвинения FiveThirtyEight (2015): сайт, продающий билеты
в кино, показывает завышенные оценки фильмов.

![Python](https://img.shields.io/badge/Python-3.10+-3776AB?logo=python&logoColor=white)
![pandas](https://img.shields.io/badge/pandas-150458?logo=pandas&logoColor=white)
![SciPy](https://img.shields.io/badge/SciPy-8CAAE6?logo=scipy&logoColor=white)

## Задача

Fandango одновременно показывает рейтинги и продаёт билеты - конфликт интересов. Обвинение разложено на три проверяемых вопроса:

1. Совпадают ли отображаемые звёзды с посчитанным рейтингом?
2. Выше ли сам рейтинг, чем у независимых площадок?
3. Если завышение есть - одинаково ли оно для всех фильмов?

## Данные

[fivethirtyeight/data/fandango](https://github.com/fivethirtyeight/data/tree/master/fandango),
выгрузка от 24 августа 2015.

| Файл | Содержание |
|---|---|
| `fandango_scrape.csv` | 504 фильма: `STARS` (показано на сайте), `RATING` (из разметки страницы), `VOTES` |
| `all_sites_scores.csv` | 146 фильмов: Rotten Tomatoes, Metacritic, IMDb - критики и зрители |

После удаления фильмов без отзывов (69) и объединения датасетов - **145 фильмов**.

## Результаты

**1. Округление одностороннее**

| | |
|---|---|
| Округлено вверх | 328 из 328 изменённых (100%) |
| Округлено вниз | 0 |
| Биномиальный тест | p = 3.7e-99 |
| Надбавка больше 0.25 балла | 180 фильмов - честным округлением необъяснимо |
| Средняя надбавка | +0.21 балла (максимум +1.00) |

**2. Завышен и сам рейтинг**

Медиана Fandango - 3.90 против 3.20 у площадок. Все 5 парных сравнений значимы
после поправки Холма, разница от +0.45 до +1.05 балла. Систематическое смещение
по Бланду-Альтману: **+0.69 балла**.

**3. Чем хуже фильм, тем больше разрыв**

Наклон регрессии −0.72 (p = 6.3e-12, R² = 0.28).

| Квартиль по качеству | Разрыв |
|---|---|
| Худшие 25% | **+1.55** |
| Лучшие 25% | −0.10 |

Рекорд - *Taken 3*: 4.5 звезды на витрине при консенсусе 1.88.

## Методы

- **Биномиальный тест** - направление округления
- **Уилкоксон для связанных выборок** + парный t-тест как контроль; данные парные,
  распределения скошены
- **Поправка Холма** на 5 сравнений, **дельта Клиффа** как размер эффекта,
  бутстрэп-интервалы (10 000 итераций)
- **Диаграмма Бланда-Альтмана** вместо регрессии разницы на рейтинг конкурентов -
  последнее даёт ложную корреляцию даже на случайных данных (ловушка Олдхэма)
